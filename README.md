# React Projects Showcase

A React-based project showcase application that displays projects categorized into **Static, Responsive, and Dynamic** categories.

## 🚀 Features

* View projects by category
* Filter projects using tabs
* Reusable React components
* Dynamic project rendering
* Responsive project cards
* Clean and simple UI

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS

## 📚 React Concepts Used

* Class Components
* State
* Props
* Event Handling
* `map()`
* `filter()`
* Component Reusability
* Conditional Rendering

## 📂 Project Categories

* **Static** – Static website projects
* **Responsive** – Responsive web projects
* **Dynamic** – Interactive/API-based projects

## ⚙️ How to Run

```bash
npm install
npm start
```

Then open the application in your browser.

## 🎯 Purpose

This project was built to practice React fundamentals such as state management, props, component communication, list rendering, and filtering data based on user selection.
